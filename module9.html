9.1 Data Validation & Dropdown Lists

Data validation controls what users can enter. Dropdowns are useful for consistent categories such as Region, Status, or Product.

Example: A Region column can allow only Manila, Cebu, Davao.
Data → Data validation → Add rule → Dropdown

Why it matters: Consistent entries make filtering, formulas, Pivot Tables, and analysis more reliable.

9.3 FILTER Function

FILTER returns only rows that meet a condition. The result updates when the source data changes.

=FILTER(A2:E11,D2:D11="Davao")

Returns rows where Region is Davao.

=FILTER(A2:E11,E2:E11>30000)

Returns rows where Sales is greater than ₱30,000.

Multiple conditions:
=FILTER(A2:E11,D2:D11="Davao",E2:E11>30000)

9.4 SORT & UNIQUE

SORT dynamically orders data. UNIQUE returns distinct values.

=SORT(A2:E11,5,FALSE)

Sorts the range by column 5, highest to lowest.

=UNIQUE(D2:D11)

Creates a list of unique regions.

Useful combination: =SORT(UNIQUE(D2:D11)) creates a unique sorted list.

9.5 QUERY Function — Introduction

QUERY lets you ask questions of a range using a SQL-like language. It is useful for reports and analysis.

=QUERY(A1:E11,"SELECT A,B,E WHERE D='Davao'",1)

Selects Order ID, Date, and Sales while keeping Davao rows. The final 1 identifies one header row.

=QUERY(A1:E11,"SELECT D,SUM(E) GROUP BY D",1)

Summarizes total sales by Region.

Remember: Put text criteria inside quotes, such as 'Davao'.

9.6 ARRAYFORMULA

ARRAYFORMULA lets one formula work across multiple rows or columns instead of entering the same formula repeatedly.

=ARRAYFORMULA(IF(A2:A11="","",E2:E11*10%))

This calculates 10% of Sales for every populated row.

Good use case: You add rows regularly and want one formula to handle a whole column.
