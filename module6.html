Module 6 · Lookups

6.1 What Are Lookup Functions?

Lookup functions help you find information in a table and return related information. They are useful for customer, product, employee, and sales data.

Remember: A lookup connects a value you know, such as a product code, to information you want, such as its price.
FormulaPurpose
=VLOOKUP(A2,$H$2:$J$6,3,FALSE)Find A2 in the first column and return column 3
=VLOOKUP(A2,$H$2:$J$6,2,FALSE)Return the category for A2
=XLOOKUP(A2,$H$2:$H$6,$J$2:$J$6,"Not Found")Find A2 and return its price

6.2 VLOOKUP Basics

VLOOKUP searches the first column of a table and returns information from another column in the same row.

Remember: A lookup connects a value you know, such as a product code, to information you want, such as its price.
FormulaPurpose
=VLOOKUP(A2,$H$2:$J$6,2,FALSE)Return the category for A2
=XLOOKUP(A2,$H$2:$H$6,$J$2:$J$6,"Not Found")Find A2 and return its price
=MATCH(A2,$H$2:$H$6,0)Find the position of A2

6.3 Exact Match

For most business lookups, use FALSE for an exact match. Example: =VLOOKUP(A2,$H$2:$J$6,3,FALSE).

Remember: A lookup connects a value you know, such as a product code, to information you want, such as its price.
FormulaPurpose
=XLOOKUP(A2,$H$2:$H$6,$J$2:$J$6,"Not Found")Find A2 and return its price
=MATCH(A2,$H$2:$H$6,0)Find the position of A2
=INDEX($J$2:$J$6,MATCH(A2,$H$2:$H$6,0))Return a price using INDEX + MATCH

6.4 XLOOKUP

XLOOKUP lets you specify the lookup range and return range separately, making it flexible and easy to read.

Remember: A lookup connects a value you know, such as a product code, to information you want, such as its price.
FormulaPurpose
=MATCH(A2,$H$2:$H$6,0)Find the position of A2
=INDEX($J$2:$J$6,MATCH(A2,$H$2:$H$6,0))Return a price using INDEX + MATCH
=IFERROR(VLOOKUP(A2,$H$2:$J$6,3,FALSE),"Not Found")Show a friendly result when no match exists

6.5 INDEX & MATCH

INDEX returns a value from a position, while MATCH finds the position of an item. Together they can perform flexible lookups.

Remember: A lookup connects a value you know, such as a product code, to information you want, such as its price.
FormulaPurpose
=INDEX($J$2:$J$6,MATCH(A2,$H$2:$H$6,0))Return a price using INDEX + MATCH
=IFERROR(VLOOKUP(A2,$H$2:$J$6,3,FALSE),"Not Found")Show a friendly result when no match exists
